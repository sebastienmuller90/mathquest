# Finot Académie — standard de contenu pédagogique

Ce dossier regroupe les banques et futures ressources destinées à enrichir les cours au-delà des exercices procéduraux.

## Structure cible d'un chapitre

Chaque chapitre doit tendre vers six briques :

1. **Cours** : notion, vocabulaire, méthode et exemples.
2. **Objet à étudier** : document, texte, schéma, tableau, graphique, carte, situation ou expérience.
3. **Compréhension** : observer, prélever une information, interpréter et justifier.
4. **Entraînement** : facile, moyen et difficile.
5. **Transfert** : réutiliser la notion dans une situation nouvelle.
6. **Remédiation Finot** : erreur typique, indice progressif et méthode de correction.

## Provenance et honnêteté documentaire

Toute ressource doit appartenir explicitement à l'une de ces catégories :

- `source` : document réel dont la provenance/licence est connue ;
- `creation` : texte, situation, dialogue, schéma ou autre ressource originale créée par Finot Académie, sans prétention à reproduire un document existant ;
- `reconstitution` : création pédagogique originale qui reconstitue explicitement un contexte historique, scientifique ou technique, jamais présentée comme une source authentique ;
- `synthese` : document Finot Académie construit à partir d'informations déjà présentes dans le cours ;
- `simulation` : valeurs ou données inventées uniquement pour entraîner une méthode de lecture/calcul.

Une `simulation` ne doit jamais être présentée comme une statistique historique, scientifique ou institutionnelle réelle. Une `synthese` ne doit jamais être appelée « document d'époque ». Une `creation` doit être signalée comme originale lorsqu'un élève pourrait la confondre avec un extrait publié. Une `reconstitution` doit être clairement identifiée comme telle dans son contenu.

## Qualité pédagogique minimale

Une activité enrichie doit préciser autant que possible :

- le chapitre et la matière ;
- la micro-compétence visée ;
- le niveau conseillé (`facile`, `moyen`, `difficile`) ;
- la consigne ;
- les informations nécessaires ;
- la réponse attendue lorsqu'elle est corrigée automatiquement ;
- une justification ou une méthode ;
- une erreur typique à éviter ;
- une situation de transfert.

## Difficulté

### Facile
- texte court ;
- vocabulaire accessible ;
- une opération mentale principale ;
- guidage explicite ;
- indices visuels ou étapes.

### Moyen
- plusieurs informations ;
- méthode à choisir ;
- justification courte ;
- transfert proche du cours.

### Difficile
- informations potentiellement non utiles ;
- plusieurs étapes ;
- comparaison de stratégies ou de documents ;
- justification développée ;
- transfert vers une situation nouvelle.

## Documents réels et images

Pour les futurs documents historiques, artistiques ou scientifiques externes : privilégier domaine public, CC0, licences compatibles ou sources institutionnelles dont les conditions permettent la réutilisation. Conserver la provenance et la licence dans les métadonnées. Ne jamais intégrer une image trouvée uniquement via un moteur de recherche sans remonter à sa source.

## Principe de Finot

Finot doit aider sans remplacer le raisonnement :

1. reformuler la consigne ;
2. rappeler la micro-compétence ;
3. signaler une erreur typique probable ;
4. donner un indice ;
5. proposer une étape intermédiaire ;
6. ne donner la solution complète qu'en dernier recours lorsque l'activité le permet.
